# Freshour · ระบบตั้งราคาหมูสด — ต้นแบบใช้งานได้

ต้นแบบที่ **กดได้ทุกปุ่ม บันทึกแล้วเปลี่ยนจริง** สร้างจากไฟล์ดีไซน์ล่าสุด (`Freshour-ทุกหน้า-ล่าสุด.html`) แบบเป๊ะๆ:
หน้าเว็บ 12 หน้า + CSS/JS เอามาจากไฟล์นั้นตรงๆ ไม่แก้ดีไซน์ · ข้อมูลตั้งต้นคือข้อมูลจริง ณ 15 ต.ค. 2569 ที่ฝังอยู่ในไฟล์ (363 SKU · 43 ลูกค้า · 517 บรรทัดสัญญา)
สิ่งที่สร้างเพิ่มคือ **หลังบ้าน** (`src/store.js`) ที่ทำให้ทุก endpoint ที่หน้าเว็บเรียก (50+ เส้น) ตอบกลับด้วยสัญญาเดียวกับระบบจริง และแก้ข้อมูลจริงเมื่อกดบันทึก

> ⚠ มีทุน/margin จริงอยู่ในข้อมูล — ห้ามส่งให้เซลล์หรือคนนอก

## เปิดใช้ 2 แบบ

| แบบ | เหมาะกับ | วิธี |
|---|---|---|
| **ไฟล์เดียว** `dist/freshour-demo.html` | กดดู/ทดสอบทันที ไม่ต้องติดตั้งอะไร | `npm run build:demo` แล้วเปิดไฟล์ในเบราว์เซอร์ (Chrome/Edge/Safari รุ่นใหม่) · สิ่งที่บันทึกเก็บในเครื่องนั้น · ปุ่ม "ล้างข้อมูลทดสอบ" อยู่มุมบน |
| **เซิร์ฟเวอร์จริง** | ทดสอบหลายคนพร้อมกัน / หลายเครื่อง / ลิงก์ลูกค้า | `npm start` → http://localhost:8787 (ต้อง Node ≥ 18 · ไม่มี dependency) |

```bash
npm start                                   # เปิดที่ :8787 · เลือกชื่อแล้วเข้าได้เลย (ไม่ต้องใส่รหัส)
FH_PINS=boss:1234,ops:2345,sale:3456 npm start   # เปิดโหมดใส่รหัสเหมือนเว็บจริง
npm run reset                               # ล้างสิ่งที่ทดสอบไว้ กลับชุดตั้งต้น (ลบ data/journal.jsonl)
npm test                                    # ทดสอบ 12 ชุด (flow ครบวง + 6 เรื่องรอบ 2)
```

## Flow ที่ทดสอบได้ครบวง (ตามรอบสัปดาห์ อ. → พ. → พฤ.)

```
อังคาร   ทุน/ตลาด     กรอกทุน · วาง Excel · ± ปรับทุกตัว · ราคาคู่แข่ง · เพิ่มสินค้า     → ราคากระดาน/margin/ขั้นต่ำ คิดใหม่ทุกหน้า
พุธ      ตั้งราคา     Step 1 ยืนยันราคากลาง → Step 2 ใบรายเจ้า (เลือก Goal · ข้อยกเว้นต้องมีเหตุผล) → ส่ง Sales
พฤหัส    ทีมขาย       ข้อความ LINE / ลิงก์ลูกค้า (/q/…) → ส่งแล้ว → ลูกค้ายืนยัน/ไม่เอา/ขอต่อรอง
         ตั้งราคา     คำขอต่อรองเด้งกลับ Pricing → อนุมัติราคาใหม่ (ต้องเห็นรุ่นล่าสุด ไม่งั้น 409) → เซลล์เห็นทันที
         ทีมขาย       ลูกค้าตอบครบ → บันทึก invoice (ยอดขายจริง)
         ผู้บริหาร    Revenue · AR · รับเงิน · Delivery · Service Log · Prospect · นำเข้า e-Today · ประกาศรอบใหม่ (ทุกเจ้ากลับเป็นยังไม่ส่ง)
```

กติกาที่หลังบ้านบังคับเหมือนของจริง: เซลล์ยืนยันได้เฉพาะราคาที่ Pricing อนุมัติ · ต่ำกว่าขั้นต่ำต้องมีเหตุผล · floor ตั้งต่ำกว่า 12% ไม่ได้ ·
ปิด Service Log ต้องมีสาเหตุ+วิธีแก้ · เรื่องขนส่งต้องบอกผู้ขนส่ง · ราคาสัญญาต่ำกว่าครึ่งทุน = พิมพ์ผิด · เลข invoice ซ้ำไม่รับ · กดรับเงินซ้ำ = รายการเดียว

## สิ่งที่เพิ่มตามคอมเมนต์ผู้ใช้ (รอบ 2 · เรียงตาม flow งาน)

| ขั้น | ที่เคยขาด | ตอนนี้ | อยู่ที่ |
|---|---|---|---|
| ทุนเข้า | ต้องพิมพ์ทุนจากไฟล์ AL เอง · ไม่มีใครเช็กทุน 3 บาท | **นำเข้าไฟล์ AL** (CSV/Excel) จับคู่ชื่อกับ SKU เอง · **ด่านตรวจ**: ทุน ≤10 · กระโดด ≥30% · สูงกว่าราคาขาย · ต่ำกว่าครึ่งของหมวด → กันไว้ให้คนยืนยันทีละตัว | ทุน/ตลาด → ปุ่ม "นำเข้าไฟล์ทุน AL" · การ์ดท้ายหน้า |
| เทียบตลาด | พิมพ์ราคา Makro/Betagro เอง · ข้อมูลเก่า · ไม่มีใครอ่านแนวโน้ม | **connector ดึงเองทุก 24 ชม.** (`MARKET_FEED_URL` · ตอนนี้ต่อ feed ตัวอย่าง) · จับคู่ SKU เพิ่มเรื่อยๆ · **หน้าแนวโน้ม**: ตลาดไปทางไหน/ควรระวังอะไร · **คะแนนเตือนถูก**: ทุกคำทำนายล็อกไว้ แล้วตรวจกับราคาจริงเมื่อครบ 7 วัน | หน้า "แนวโน้มตลาด" |
| ส่งราคา | ราคาไปไม่ถึงลูกค้าเอง · ไม่รู้ว่าใครตอบแล้ว | **ส่ง LINE** รายเจ้า/ทุกเจ้าที่พร้อม (outbox · ส่งจริงเมื่อตั้ง `LINE_CHANNEL_TOKEN` · ไม่ตั้ง = จำลอง) · **กระดานสถานะ** 9 ขั้น: รอ Pricing → พร้อมส่ง → ส่งแล้ว → ต่อรอง → ตอบบางส่วน → ตอบครบ → ปิดได้/เสีย → invoice · webhook รับคำตอบลูกค้า ("ตกลง" = รับทั้งใบ · "ขอ สินค้า ราคา" = คำขอต่อรอง) | หน้า Sales (บนสุด) |
| ต่อรองจนจบ | ไม่มีใครตามเจ้าที่เงียบ · ไม่บันทึกว่าจบที่ราคาไหน | **คิวตามลูกค้า**: ส่งแล้วไม่ตอบเกิน 2 วันขึ้นแดง · บันทึกว่าตามแล้ว (โทร/LINE อัตโนมัติ) · **ปิดดีล**: ได้ = เก็บราคาที่ตกลงทุก SKU + margin จริง · เสีย = ต้องบอกเหตุผล | กระดาน Sales → ปุ่ม "ตามลูกค้า" / "ปิดดีล" |
| Log | จดกระจัดกระจาย ร้อยกันไม่ได้ · ระบบล้มไม่มีใครรู้ | **log กลางรูปแบบเดียว** ทุกคำสั่งของคน + งานของระบบ + คำตอบลูกค้า (เวลา · ใคร · ทำอะไร · กับอะไร · ผล · ขั้นของ flow) · **health**: งานระบบ 3 ตัวต้องรายงานรอบ · ล้ม/ขาดรอบ = alert บนหน้าแรกทุกคน + LINE ผู้ดูแล (`LINE_ADMIN_USER_ID`) · `/api/health` ตอบ 503 ให้ monitor ภายนอก | หน้า "บันทึกเหตุการณ์" |
| Dashboard | ไม่มีหน้าไหนบอกผลลัพธ์ | **พี่หมิง**: ปิดได้กี่เจ้า · margin จริง vs ราคากลาง vs สัญญา · มูลค่าที่ได้/เสีย + เหตุผล · **พี่จุ๋ม**: งานติดตรงไหน (ลิงก์ไปทำ) · ทุนเก่า/ไม่รู้ · ตลาดสด/เก่า/ไม่รู้ · ทุนแปลกรอตรวจ · **เซลล์**: กระดานทุกเจ้าอยู่ขั้นไหน (ไม่มีทุน/margin ในทุก payload) | บนหน้าแรกของแต่ละบทบาท |

ตัวแปรแวดล้อมเพิ่ม: `LINE_CHANNEL_TOKEN` `LINE_CHANNEL_SECRET` `LINE_ADMIN_USER_ID` `MARKET_FEED_URL` · `FH_JOBS=0` ปิดงานอัตโนมัติ (ใช้ตอนทดสอบ)

## ต้นแบบนี้ต่างจากระบบจริงตรงไหน

- หลังบ้านจริงคือ Cloudflare Worker + D1 — ตัวนี้จำลองสัญญาของทุก endpoint และกฎธุรกิจหลัก แต่ **ไม่ใช่โค้ด production** (ไม่มี LINE webhook / cron / บอท)
- เครื่องคิดราคา V29 ของจริงซับซ้อนกว่า: ที่นี่ทุนเปลี่ยนแล้ว ราคาขยับเฉพาะตัวที่ตั้งด้วยสูตร ทุน×1.6 หรือตัวที่หลุดเป้าหมวด (ดันขึ้นถึงขั้นต่ำ) — ไม่ลดราคาเองเงียบๆ
- หน้า "สมองระบบ/ความจำ/Logic/การเชื่อมต่อ" อ่านจากภาพรวมที่จับมา ณ วันที่ 15 ต.ค. ส่วนสรุปที่คำนวณได้ (กำไร/สัปดาห์ · ทุนเฉลี่ย · รอบที่ประกาศ · บทสนทนา brain · audit) อัปเดตตามที่ทดสอบ
